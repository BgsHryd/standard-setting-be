## Temuan yang diperbaiki selama QA/review

1. Riwayat butir BSON null menyebabkan `$addToSet` gagal; array dinormalisasi dan data lama kompatibel.
2. Reset bersamaan dengan change-password: write dikondisikan pada authVersion dan sesi baru diikat pada versi hasil write.
3. Respons peserta nonaktif tidak lagi menghambat completion atau tampil di hasil operasional.
4. Snapshot menyimpan ID pembentuk statistik agar pergantian akses tidak membuat tabel respons menyimpang tanpa informasi.
5. Putaran belum tersedia direpresentasikan per-mapel, tidak menggagalkan agregat.
6. Modal Clear all kini di atas drawer dengan latar drawer inert; navigasi mobile menampung empat menu.
7. Panel impor di-key berdasarkan langkah sehingga file/preview langkah lain tidak terbawa.

## Batas cakupan

File template dihasilkan dan dibaca ulang dengan Excelize; roundtrip, validasi, atomicity, dan upload browser diuji. Pembukaan/edit manual menggunakan aplikasi Microsoft Excel desktop dan audit screen reader/WCAG menyeluruh belum dilakukan. Riwayat butir yang sudah hilang dari data lama tidak direkonstruksi. Grafik statistik merupakan deskriptif; tidak ada ICC atau confidence interval yang dikarang.

Database QA UI dipertahankan untuk reproduksi; kredensial QA hanya untuk data percobaan tersebut. Operasi normal mengikuti `.env` pengguna. Lihat [cara menjalankan lokal](../../../README.md) dan [panduan pengguna](../../../frontend-ss/docs/ADMIN-2026-10-14.md).
