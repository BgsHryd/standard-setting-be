## 1. Kesimpulan pengujian

Alur utama Admin sebagian berhasil: proyek QA dibuat, butir tiga jenis dipilih, akun dibuat, proyek diaktifkan, form konfigurasi memuat data lama, dan proyek diselesaikan sehingga butir berflag Sudah Diuji. Namun monitoring/preview masih menunjukkan angka atau respons demo; beberapa action belum berfungsi.

Login PIC berhasil menuju dashboard, tetapi request monitoring PIC ditolak 403 dan UI menampilkan dataset demo. Dua tahap konfirmasi finalisasi/rollback dapat dibuka dan dibatalkan; eksekusi round tidak dijalankan.

Login Panelis berhasil menuju /panelis, tetapi area utama kosong. Console menampilkan DataCloneError dan pembacaan property value yang belum ada. GET form Panelis juga ditolak 403. Pengisian, autosave, history nyata dan perpindahan round belum berhasil diuji end-to-end.

**Keputusan QA:** belum lulus keseluruhan. Perlu memperbaiki akses API role, rendering Panelis dan pemisahan data nyata/demo sebelum retest alur penilaian.

**Ringkasan matriks 28 kasus:** 16 Lulus, 3 Parsial, 4 Gagal, 3 Terblokir, dan 2 Tidak dijalankan. Kasus Lulus mencakup langkah UI tertentu, bukan sertifikasi seluruh workflow.

## 8. UX, aksesibilitas, dan retest yang diperlukan

Kekuatan UI: warna dan styling konsisten, wizard lima tahap mudah diikuti, progress bar disertai jumlah, ikon mata membuka preview, serta konfirmasi dua tahap mengurangi salah klik. Feedback password memberikan informasi sama/belum sama secara tekstual.

Kekurangan UX: data demo tidak diberi penanda yang memadai ketika API gagal; label tersimpan/sinkron berpotensi menyesatkan; tanggal invalid dan label Draft pada proyek aktif mengurangi kejelasan status. Beberapa tombol tampak operasional tetapi belum mempunyai aksi.

Aksesibilitas yang diamati: beberapa tombol icon/input tidak mempunyai nama aksesibel; modal/drawer belum memiliki role dialog, fokus terperangkap, atau pengembalian fokus yang terverifikasi; tabel div belum semantik tabel. Ini observasi DOM/source/visual, bukan audit WCAG lengkap. Tidak dilakukan screen-reader, keyboard menyeluruh, contrast measurement formal atau mobile browser matrix.

Retest prioritas:

1. Perbaiki middleware role lalu uji 200 role benar, 403 role salah dan scope proyek/mapel/Panelis lain.
2. Perbaiki render form dan uji semua jenis soal, input kosong/invalid, autosave, error jaringan, resave dan persistensi MongoDB.
3. Uji ganti password valid lalu request protected/refresh/logout dan expired session.
4. Ganti data demo/statistik dengan hasil nyata; gunakan dataset statistik yang dihitung manual, final round dan panelis unik.
5. Eksekusi finalisasi/rollback, pembaruan form seluruh Panelis, history, dan finalize ulang setelah rollback.
6. Uji Draft tidak lengkap, resume/edit, generate ulang, konflik alokasi, hapus Draft, dan penyelesaian hanya ketika siap.
7. Selesaikan tombol yang belum terhubung dan verifikasi keyboard/fokus/dialog/responsive.

Unit test/build tidak tercatat sebagai verifikasi akhir audit role ini. Verifikasi baru untuk pekerjaan dokumentasi/migration dipisahkan pada VERIFIKASI-DOKUMEN.md. Laporan ini tidak menaikkan status fitur yang terblokir menjadi lulus.
